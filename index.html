Sending Us a File?

Here's what we need for a clean, on-color print run — we're happy to check your file before it goes to press.

Resolution
300 DPI minimum

At final print size, to keep images and fine detail sharp off the press.

Color mode
CMYK, not RGB

We convert and proof in CMYK so on-screen colors match the printed result.

Bleed & margins
3mm bleed / 5mm safe area

Keeps background color running to the trim edge and text away from the cut line.

File formats
PDF, AI, high-res TIFF

Vector where possible; layered source files help if last-minute edits are needed.
